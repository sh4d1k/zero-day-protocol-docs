## 2. Collecting and Using Your Personal Data

### Types of Data Collected

#### A. Personal Data
While using Our Service, We may collect certain personally identifiable information to provide user authentication and cloud synchronization:
* **Email address** (When signing in via Google Sign-In or Firebase Authentication)
* **Display Name and User ID (UID)** (Generated by Google/Firebase to sync player progress across devices)
* **Game State & Profile:** Unlocked nodes, cryptographic cipher scores, hardware upgrades, and virtual credit balances stored securely in Firebase Firestore.

#### B. Usage Data & Diagnostics
Usage Data is collected automatically when using the Service. This may include information such as Your Device's IP address, device model, operating system version, unique device identifiers, in-game performance metrics, and crash diagnostic logs to help us resolve software bugs.

#### C. Device Permissions
* **`INTERNET`**: Required for cloud database synchronization, user authentication, and game data retrieval.
* **`VIBRATE`**: Used for tactile haptic feedback during interactive terminal operations and puzzle solving.
* *(Note: Zero Day Protocol does **NOT** record, capture, or store microphone/audio data).*
